# 机械制图 · 分步绘图教练

**一句话**：把一张已经画好的工程图喂进去，它把图拆成一条条笔画，按机械制图的规矩排好先后顺序，然后一笔一笔动给你看。

---

## 怎么用

双击 **`机械制图分步教练.html`**（就在 `dsh\` 根目录）。

单个文件，不用装任何东西，不用联网，不写注册表。拷到 U 盘、发微信给同学都能直接打开。

### 第一次打开，先看示例

点右上角 **「示例图纸」** → 程序现画一张「L 形支架」三视图（带中心线、虚线、尺寸），然后自动解析。
按 <kbd>空格</kbd> 播放，看着图一笔一笔长出来。

### 换成自己的图

| 方式 | 操作 |
| --- | --- |
| 拖 | 把图片直接拖进窗口 |
| 选 | 点「导入图纸」 |
| 粘 | 截图后 <kbd>Ctrl</kbd>+<kbd>V</kbd> |

导入后：

1. **框掉文字**（重要）：点「框掉文字」，在画布上把尺寸数字、标题栏、技术要求框起来。这些文字会被当成线条，框掉之后步骤干净很多。
2. **生成步骤**：点按钮，等 0.2 秒左右。
3. **播放**：<kbd>空格</kbd> 播放/暂停，<kbd>←</kbd><kbd>→</kbd> 单步，拖动进度条随意跳。
   - 已经画完的线是**黑色**
   - 当前这一步正在画的是**朱红色**，笔尖会跟着走
   - 右边步骤列表自动高亮当前步
4. **改顺序**：右边每一步可以 ↑↓ 调顺序、⇤ 并入上一步、✕ 删除；双击标题或要点能直接改字；点线型徽章（中心线/粗实线/虚线…）能换线型。改完动画立刻跟着变。
5. **导出**：右下角「导出 PNG」把完成的图画出来存成图片。

## 它到底做了什么

```
位图  →  矢量笔画  →  按制图规范排序  →  动画
```

1. **二值化**：自适应阈值（翻拍/扫描件光照不均也能用），也可以手动调阈值。
2. **估线宽**：对每个墨点算到最近背景的距离，得到「粗实线 / 细实线」的分界。
3. **细化**：Zhang-Suen 算法把线条削成 1 像素宽的骨架。
4. **追踪**：沿**方向连续性**贪心前进，把骨架串成折线。这一点很关键——直接按“交叉点”切，锯齿状的骨架会被切成上万个碎片。
5. **简化**：Douglas-Peucker 把折线压成少量关键点。
6. **接断口**：端点靠近 + 方向对得上 + **线宽一样**才接。加线宽这一条，是为了不让引线跟圆连成一条、细线跟粗线连成一条。
7. **认线型**：把同一直线上断开的短划连起来，看**中间有没有一个明显更短的点**——
   有，是点划线（中心线）；没有、划长都差不多，是虚线。
8. **认圆**：被中心线、引线切开的几段弧，按圆心和半径聚合，合起来能凑够一整圈才算圆。
9. **排步骤**：中心线 → 可见轮廓 → 圆 → 虚线 → 细实线。这就是教材里那套「先定基准、先大后小、最后标注」。

## 手机上用

手机上有两条路，**优先走第一条**。

### 方式一：局域网访问（不用解压、不用装 App）

前提：手机和电脑连同一个 WiFi。

1. 电脑上双击 `手机\启动-手机访问.bat`
2. 弹出的黑窗口里会列出地址，形如 `http://192.168.1.5:8123`
3. 手机浏览器照抄这个地址打开即可，功能和电脑上一模一样
   （第一次启动如果弹防火墙提示，点「允许访问」；用完按 Ctrl+C 停止）

手机竖屏会自动变成「上面看图、下面看步骤」的布局，并用手机自带的文件选择器选图——
**拍一张课本上的图，直接就能解析**。

### 方式二：传到手机再解压

- **iPhone**：微信点开 zip → 右上角「…」→ 用其他应用打开 → 存储到「文件」→ 在「文件」App 里轻点 zip 自动解压 → 点里面的 `.html`，快速预览就能用。
- **安卓**：文件管理里长按 zip 解压 → 长按 `.html` → 打开方式选浏览器。
  部分机型会显示源码而不是渲染页面，那就换个浏览器，或者装个「HTML Viewer」类的小 App。
  安卓机型差异大，这一步不一定一次成功——**能连同一个 WiFi 就用方式一**。

## 分享给别人

`机械制图分步教练.html` 是**单文件、零依赖**的：拷到 U 盘、发微信、发邮件都能用，对方双击就开。
为了方便转发，旁边还有 `机械制图分步教练-分享包.zip`（含 HTML + 使用说明）。

几个可能被卡住的地方：

| 情况 | 说明 |
| --- | --- |
| 微信/QQ 不让发 `.html` | 发 zip 包；或者把后缀临时改成 `.txt`，让对方改回 `.html` |
| 打开提示「Windows 已保护你的电脑」 | 点「更多信息 → 仍要运行」。这是所有自己传的 HTML 都会有的提示，不是病毒 |
| 文件名变成乱码 | 无所谓，改名照样能打开 |
| 手机打开 | 会自动切成「上面看图、下面看步骤」的竖排布局，能播能看；但真学画图还是在电脑上 |
| 浏览器 | Edge / Chrome 实测可用；Firefox、Safari 理论上也行（只用标准 Canvas 2D），未实测 |

> 不含任何统计、联网、外部资源。断网也能跑。

## 已知局限（先说清楚，免得你踩坑）

- **一次只喂一个视图，效果最好。** 整张 A4 图也能解析，但图框、标题栏、尺寸数字会变成一堆碎步骤。想学某个视图，就把它框出来单独喂。
- 它**不认识零件**。它知道这是一条粗实线、那是一段虚线，但不知道那是「底板」还是「立板」。所以要点文字是通用口诀，不是针对你这个零件的解读。
- **交叉多的地方会断**。圆被中心线穿过会切成几段弧（已按圆心聚合，但偶尔会漏成两半）。
- **文字很容易被当成线**。这是位图识别的通病，靠「框掉文字」手动解决，别指望自动。
- 只还原**图上已经有的线**。它不会从三视图反推三维、也不会自动生成剖视图。

## 想改它

源码在 `机械制图教练\src\`：

| 文件 | 干什么 |
| --- | --- |
| `engine.js` | 全部算法：二值化、细化、追踪、分类、排序。不依赖任何库，浏览器和 Node 都能跑。 |
| `app.js` | 界面、画布动画、步骤编辑、导出 |
| `demo.js` | 内置示例图纸（用 Canvas 现画，不是图片） |
| `styles.css` | 样式 |
| `index.html` | 页面骨架 |

改完在 `机械制图教练\` 目录里跑：

```
node build.js
```

会把 CSS/JS 内联，重新生成根目录那个单文件 HTML。

### 调试工具（`机械制图教练\tools\`）

用来肉眼检查“提取对不对”：

```
python tools/png2gray.py 图纸.png tmp\x.gray       # 图片转灰度裸数据
node   tools/test_engine.js tmp\x.gray tmp\x.gray.dim tmp\x.json 1700
python tools/overlay.py tmp\x.json tmp\overlay.png 1 kind
```

`overlay.png` 会按线型上色画出识别结果（黑=粗实线、蓝=虚线、紫=中心线、灰=细线），一眼就能看出哪里识别错了。

## 调参小抄

识别不准时，按这个顺序调（都在左栏）：

| 症状 | 调什么 |
| --- | --- |
| 线条断成一截一截 | 「断线合并」调大（4 → 6） |
| 图很糊、线条发灰 | 二值化切「手动阈值」，往低调到 100~140 |
| 满屏细碎噪点 | 「最小笔画」调大（6 → 12） |
| 粗线被当成细线 | 「处理精度」调到 2400，让线宽分得更开 |
| 深色背景白线 | 勾上「深底白线」 |
